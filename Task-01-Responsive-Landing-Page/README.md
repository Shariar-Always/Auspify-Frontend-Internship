## 📌 Project Overview
**NexFlow AI** is a cutting-edge, high-conversion SaaS landing page designed for an autonomous AI workflow and multi-agent orchestration platform. It is built strictly using modern **HTML5**, **Vanilla CSS3**, and **Vanilla JavaScript** adhering to top-tier aesthetic and responsive design standards.

---

- [x] **Dark / Light Mode Switcher:** Seamless theme toggle in navbar and mobile drawer with local storage persistence and butter-smooth color transitions.
- [x] **Sticky Glassmorphism Navbar:** Dynamic background blur on scroll, brand logo, navigation links, and action buttons.
- [x] **Mobile Drawer Navigation:** Fully animated slide-in drawer with hamburger toggle for seamless mobile browsing.
- [x] **High-Impact Hero Section:**
  - Pulsing release announcement badge (`NexFlow 2.5 is Live`).
  - Gradient typography with clear value proposition.

  - Social proof with stacked avatars and 4.9/5 star ratings.

- [x] **Trusted Brands Strip:** Social proof featuring top tech companies.
- [x] **Core Features Grid (6 Cards):** Hover lift effects, glowing icon accents, and performance metrics (10x faster execution, 99.99% uptime SLA).

  - *Visual Workflow Studio*

## 🛠️ Technologies Used

- **HTML5:** Semantic architecture (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3:** Custom properties (CSS variables), Flexbox, CSS Grid, Glassmorphism (`backdrop-filter`), keyframe animations (`orbFloat`, `pulseLive`, `fadeIn`).
- **JavaScript (ES6):** Modular event-driven functions (scroll detection, mobile drawer, tabs, pricing calculations, accordion, form validation).
- **Icons & Fonts:** Font Awesome 6, Google Fonts (`Outfit` & `Inter`).

## 🌐 How to Run Locally

1. Open `Task-01-Responsive-Landing-Page/index.html` directly in any web browser.
2. Alternatively, run a lightweight local server:
   ```bash
   python -m http.server 3000 --directory "Task-01-Responsive-Landing-Page"
   ```
   and visit [http://localhost:3000](http://localhost:3000) in your browser.
